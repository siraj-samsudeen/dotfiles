Structure every grill question so the user can answer with one keystroke:

- **Choices question:** label options A / B / C; user types a letter.
- **Yes/no question:** phrase it so "y" or "n" is unambiguous — e.g. "Same START_DATE for sales returns as invoices? (y/n)"
- **Never** end with "Do you agree?" or "Is that right?" without making it clear it's a y/n question — it reads as rhetorical and forces a longer answer.

**Why:** the user types short answers during grill sessions (y, A, etc.); an ambiguously framed question breaks that flow and makes quick iteration painful.

**How to apply:** before sending a grill question, check: can the user answer it with one or two characters? If not, restructure it.
